
# 🔄 存档点系统使用指南

## 📋 概述

存档点系统为脑区感知Subject Embedding分析提供了完整的状态保存和恢复功能，让您可以在长时间的分析过程中灵活地保存和恢复进度，大大提高调试和开发效率。

## 🎯 主要功能

### ✨ 核心特性
- **自动存档**: 每个Phase完成后自动创建存档点
- **手动存档**: 随时手动创建存档点用于调试
- **灵活恢复**: 支持自动恢复和指定恢复
- **异常保护**: 异常时自动创建紧急存档点
- **增量存储**: 优化的存储策略，避免重复数据
- **兼容性检查**: 自动检查存档点版本兼容性
- **后台运行**: 支持关闭终端后继续运行

### 📊 存档点类型
1. **Phase级存档点**: 每个分析阶段完成后自动创建
2. **手动存档点**: 用户主动创建的调试点
3. **紧急存档点**: 异常时自动创建的恢复点
4. **临时存档点**: 特定操作前的临时保存

## 🚀 快速开始

### 基础使用（支持后台运行）

```bash
# 1. 自动恢复最新存档点（推荐）
./run.sh --resume-latest

# 2. 从指定存档点恢复
./run.sh --resume-from phase2

# 3. 强制重新开始（忽略所有存档点）
./run.sh --force-restart

# 4. 列出所有可用存档点
./run.sh --list-checkpoints
```

### ⚠️ 重要提示：交互式恢复

**交互式恢复不支持后台运行！** 如果需要交互式选择存档点，请使用以下方法：

```bash
# 方法1：直接运行Python（前台模式）
python main.py --interactive_recovery

# 方法2：先列出存档点，再选择恢复
./run.sh --list-checkpoints
# 根据列表选择要恢复的存档点
./run.sh --resume-from <选择的存档点>
```

## 📝 详细使用方法

### 1. 存档点创建

#### 自动创建
系统会在以下时间点自动创建存档点：
- **Phase 0**: 数据准备完成 (`data_prepared`)
- **Phase 1**: 受试者差异分析完成 (`subject_analysis`)
- **Phase 2**: 可分离性评估完成 (`separability`)
- **Phase 3**: Embedding设计完成 (`embedding_design`)
- **Phase 4**: 最终决策完成 (`final_decision`)

#### 手动创建
```bash
# 创建指定名称的存档点后退出
./run.sh --checkpoint-and-exit "debug_feature_analysis"

# 或者在Python中
python main.py --checkpoint_and_exit "my_checkpoint"
```

#### 程序内创建
```python
# 在分析器中手动创建存档点
analyzer.save_checkpoint(
    checkpoint_name="manual_debug_point",
    description="调试特征重要性分析前的状态"
)
```

### 2. 存档点恢复

#### 🔥 后台运行模式（推荐用于生产环境）

后台运行允许您关闭终端/JupyterNotebook后程序继续运行：

```bash
# 恢复最新存档点并后台运行
./run.sh --resume-latest

# 从特定存档点恢复并后台运行
./run.sh --resume-from phase2_separability
./run.sh --resume-from "debug_feature_analysis"

# 查看后台运行的进度
tail -f ./brain_aware_analysis_output/run_*.log

# 查看进程状态
ps aux | grep main.py
```

#### 前台运行模式（用于调试）

如果需要交互式选择或实时查看输出：

```bash
# 直接运行Python，支持交互式恢复
python main.py --interactive_recovery

# 交互式界面示例：
# 🔄 检测到存档点，请选择继续方式：
# 
# [0] 重新开始完整分析
# [1] Phase 0: 数据准备完成 (2024-12-01 14:20:15) - 节省 5分钟
# [2] Phase 1: 受试者差异分析完成 (2024-12-01 14:35:42) - 节省 20分钟  
# [3] Phase 2: 可分离性评估完成 (2024-12-01 15:12:33) - 节省 57分钟
# [4] 手动存档: debug_feature_analysis (2024-12-01 15:25:10) - 节省 70分钟
# 
# 请输入选择 [0-4]: 
```

#### 按阶段名恢复
支持的阶段名：
- `phase0` 或 `data` → 数据准备阶段
- `phase1` 或 `subject` → 受试者分析阶段
- `phase2` 或 `separability` → 可分离性评估阶段
- `phase3` 或 `embedding` → Embedding设计阶段
- `phase4` 或 `decision` → 最终决策阶段

### 3. 存档点管理

#### 查看存档点信息
```bash
# 基础列表（带使用建议）
./run.sh --list-checkpoints

# 使用管理工具查看详细信息
python checkpoint_tools.py --list

# 分析空间使用
python checkpoint_tools.py --analyze-size

# 分析时间线
python checkpoint_tools.py --analyze-timeline

# 对比两个存档点
python checkpoint_tools.py --compare phase1 phase2
```

#### 清理存档点
```bash
# 模拟清理（不实际删除）
python checkpoint_tools.py --cleanup

# 实际清理（保留7天内和最新5个）
python checkpoint_tools.py --cleanup --execute

# 自定义清理策略
python checkpoint_tools.py --cleanup --cleanup-days 14 --keep-count 10 --execute
```

#### 导出存档点摘要
```bash
python checkpoint_tools.py --export-summary checkpoint_summary.json
```

## 🛠️ 高级功能


### 2. 程序内存档点操作

```python
from src.analyzer import BrainAwareSubjectEmbeddingAnalyzer

# 创建分析器（启用存档点）
analyzer = BrainAwareSubjectEmbeddingAnalyzer(enable_checkpoints=True)

# 列出存档点
checkpoints = analyzer.list_checkpoints()
for ckpt in checkpoints:
    print(f"{ckpt['name']}: {ckpt['creation_time']}")

# 加载存档点
success = analyzer.load_checkpoint("phase2_separability")
if success:
    print("存档点加载成功")

# 手动保存存档点
checkpoint_path = analyzer.save_checkpoint(
    checkpoint_name="before_visualization",
    description="可视化前的状态保存"
)
```

### 4. 深度网络状态保存

存档点系统自动保存：
- Alex版本超参数配置
- 网络训练历史
- 模型权重（可选）
- 训练缓存

### 5. 异常恢复机制

当程序异常退出时：
1. 自动创建紧急存档点
2. 保存错误信息和堆栈
3. 下次启动时可以从紧急点恢复

## 📊 性能优化

### 存储优化
- **压缩存储**: 使用gzip压缩，节省60-80%空间
- **增量保存**: 只保存变化部分
- **智能清理**: 自动清理过期存档点
- **选择性保存**: 深度网络状态可选保存

### 恢复优化
- **快速校验**: 加载前进行兼容性检查
- **部分恢复**: 只恢复必要的状态
- **智能跳跃**: 自动确定要跳过的阶段

## 🔧 配置选项

### 存档点管理器配置
```python
checkpoint_config = {
    'max_checkpoints': 15,        # 最多保留存档点数
    'auto_cleanup_days': 7,       # 自动清理天数
    'compression_level': 6,       # 压缩级别 (0-9)
    'keep_phase_checkpoints': True, # 保留Phase级存档点
    'include_deep_networks': True   # 是否包含深度网络状态
}
```

### 命令行参数
所有存档点相关的命令行参数：
```bash
--disable-checkpoints       # 禁用存档点系统
--resume-latest             # 自动恢复最新存档点（支持后台）
--resume-from CHECKPOINT    # 从指定存档点恢复（支持后台）
--list-checkpoints          # 列出所有存档点
--checkpoint-and-exit NAME  # 创建存档点后退出
--force-restart             # 强制重新开始
--interactive-recovery      # 交互式恢复选择（仅前台）
```
