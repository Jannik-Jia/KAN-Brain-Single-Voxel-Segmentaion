# Experiment JSON Integration - TODO List

## Summary

This document describes the experiment JSON schema integration for the `3_Fullyconnected_ori_mat_without_background` project.

### Experiment Classification

| Field | Value |
|-------|-------|
| **Family** | `mlp` |
| **Subfamily** | `baseline_4x4096` (default) or `deepmlp_6x2048` (BayesOpt best) |
| **Dataset** | Alex7T |
| **Grid** | MPRAGE |
| **Label Space** | `alex-101` (no label 43) |

## Created Files

1. **`experiment_json_logger.py`** - Main logger class that:
   - Follows the unified schema from `通用工具`
   - Auto-extracts config values from training config
   - Computes metrics using `MetricCalculator` from `通用工具`
   - Validates against `SchemaValidator`

2. **Updated `main.py`** - Now automatically generates experiment JSON after training

## Fields Automatically Populated

### From Config (`set_from_config`)

| Field | Source |
|-------|--------|
| `seed` | `config['random_seed']` |
| `task.label_space` | Derived from `config['num_class']` |
| `task.split.val_subjects` | `config['val_prob_idx']` |
| `task.split.test_subjects` | `config['test_prob_idx']` |
| `preprocessing.normalisation.type` | `config['standardization_method']` |
| `preprocessing.background_handling` | Derived from `filter_background`, `include_background_in_classes` |
| `model.details.*` | `hidden_units`, `activation`, `dropout_rate`, etc. |
| `training.optimizer.*` | `optimizer`, `lr`, `weight_decay` |
| `training.scheduler.*` | `lr_scheduler_type`, etc. |
| `training.batch_size` | `config['batch_size']` |
| `training.n_epochs` | `config['epochs']` |
| `training.early_stopping` | Auto-selected (short-term or long-term template) |

### From Runtime

| Field | Source |
|-------|--------|
| `code_version` | `git rev-parse --short HEAD` |
| `hardware.gpu` | `torch.cuda.get_device_name(0)` |
| `hardware.num_gpus` | `torch.cuda.device_count()` |
| `model.param_count_m` | Calculated from model |
| `task.n_voxels.*` | From `dataset_dict` |
| `results.global_metrics.*` | From `evaluate_model()` output |

## Consistency Checks (Required by Schema)

### MLP Family Requirements

For `family: "mlp"`, `model.details` must include:

- [x] `input_dim` - Set from `config['feature_dim']`
- [x] `output_dim` - Set from `config['num_class']`
- [x] `hidden_layers` - Set from `config['hidden_units']`
- [x] `activation` - Set from `config['activation']`
- [x] `dropout` - Set from `config['dropout_rate']`
- [x] `residual` - Set based on `model_type`
- [x] `attention` - Default `false` for standard MLP
- [x] `feature_interaction` - Default `false` for standard MLP

### Preprocessing Consistency

- [x] If `subfamily` contains `per_patient`, then `normalisation.type` should be `per_patient_zscore`
  - Current default: `patientwise` -> `per_patient_zscore`
- [x] If `subfamily` contains `global`, then `normalisation.type` should be `global_standard_scaler`

## Usage Instructions

### Automatic (Default)

Simply run `main.py` as usual. The experiment JSON will be automatically generated and saved to the results directory.

```bash
python main.py --config my_config.json
```

### Manual/Custom

```python
from experiment_json_logger import ExperimentJSONLogger, create_experiment_logger_from_config

# Method 1: From config
logger = create_experiment_logger_from_config(
    config,
    experiment_id="my_custom_experiment_v1",
    method_name="My Custom Method Name"
)

# Method 2: Manual initialization
logger = ExperimentJSONLogger(
    experiment_id="alex_deepmlp_6x2048_patientwise_v1",
    method_name="Deep MLP 6x2048",
    method_key="deepmlp_6x2048",
    family="mlp",
    subfamily="deepmlp_6x2048"
)

# Configure
logger.set_from_config(config)
logger.set_voxel_counts(train=5000000, val=150000, test=150000)
logger.set_model_param_count(model)

# Log results
logger.log_results_from_eval_dict(test_results, split="test")

# Save
logger.save("./results/experiment_name")
```

## Validation

The logger automatically validates against the schema. Check for warnings in console output:

```
Schema validation passed.
```

Or warnings like:

```
Schema validation warnings for alex_deepmlp_6x2048_v1:
  - Family 'mlp' requires 'model.details.input_dim'
```

## Notes

1. **BayesOpt experiments**: When running BayesOpt, only create JSON for the final retrained model with best hyperparameters, not for each trial.

2. **Early stopping templates**:
   - Short-term (epochs ~30-40): `min_epochs=15, patience=5`
   - Long-term (epochs ~100): `min_epochs=40, patience=10`

3. **Label space**:
   - `alex-101`: 101 classes (label 43 removed)
   - `alex-102`: 102 classes (original)
   - `alex-100`: 100 classes (background filtered)
